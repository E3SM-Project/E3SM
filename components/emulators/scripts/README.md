# Emulator scripts

| Directory | Contents |
| --- | --- |
| `config/` | Python helpers for generating emulator configs and coupling plans. |
| `config/examples/` | Configs and plans generated by `create_coupling_test_files.py`. |
| `cpl7/` | Tools for working with the field lists in the `CPL7` driver's `seq_flds_mod.F90`. |
| `shell/` | Shell functions used by the `test` script. |

See "Configuration" in the package README for how to use the helpers in `config/`.
